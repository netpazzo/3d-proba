# 3D proizvodi za webshop

Demo stranica Studija 19: 3D preglednik proizvoda s okretanjem i zumiranjem, prikazom „Pogledaj u svom prostoru” (AR na mobitelu, preko https), fotografijama iz 3D modela i konfiguratorom s cijenama (model-viewer).

Adresa: https://netpazzo.github.io/3d-proba/

| Mapa | Primjer |
|---|---|
| `/` | izlog s tri primjera |
| `fotelja/` | fotelja s 3D i AR prikazom |
| `auto/` | konfigurator automobila: boje, spojleri, naplatci, kočione čeljusti, cijene i usporedba |
| `slusalice/` | slušalice s izborom boje i galerijom fotografija iz 3D modela |
